# Grill me interactively

1. **Establish the goal.** If the goal is still unclear, ask one open question about what the user wants to understand or decide.
2. **Work through the decisions.** Ask the most consequential open question whose prerequisites are settled. Look up available facts and leave decisions to the user. For a concrete choice, explain the tradeoff and put your recommendation first when supported. Use the interactive question tool when it fits or ask in chat. Wait for each answer, then revisit which decisions it opens or rules out. Continue until every relevant decision is settled or explicitly deferred.
3. **Confirm the outcome.** Summarize the decisions and deferred questions, then ask the user to confirm or correct them. Begin implementation only if the user explicitly requests it.
