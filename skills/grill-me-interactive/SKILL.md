# Grill me interactively

1. **Start with the goal.** If the idea is still forming, ask an open question about what the user wants to understand or decide. As choices emerge, map their dependencies so foundational decisions come first.
2. **Ask one question.** Pick the most consequential open question whose prerequisites are settled. Look up facts available in the code, tools, or conversation before asking. For a concrete choice, explain the tradeoff and put your recommendation first when the evidence supports one. Use the interactive question tool when it fits, or ask in chat. Wait for the answer before continuing.
3. **Update the decision tree.** Follow the branches the answer opens and drop the ones it rules out. Continue until every relevant decision is settled or explicitly deferred by the user.
4. **Confirm the outcome.** Summarize the shared understanding, decisions, and open questions. Ask the user to confirm or correct it. Begin implementation only if the user explicitly requests it.
