# Draft a Slack message

1. **Read the context.** For a thread reply, read the conversation from the Slack link or use the excerpt the user provides. If the thread is inaccessible and the reply depends on it, ask for the relevant messages.
2. **Verify the references.** Look up only the references the recipient needs, such as a PR, Jira issue, or Datadog dashboard. Check that each link points to the item or metric the draft describes. If access is missing, use the context you can verify or ask for the missing link if it is essential.
3. **Return one draft in chat.** Start with the point or ask, use a casual colleague's voice, and put links inline. Default to 2–5 short lines of plain text without headings or a preamble. Use simple hyphens when you need dashes or bullets. For a small revision, edit the requested wording and keep the rest of the draft.

This skill ends at the draft.
