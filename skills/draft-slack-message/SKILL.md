# Draft a Slack message

1. **Gather context.** For a reply, read the linked Slack thread or the supplied excerpt. Verify each link you intend to include against the PR, issue, dashboard, or metric it describes. Ask for a missing excerpt or link only if the draft depends on it.
2. **Draft in chat.** Return one plain-text draft, usually 2–5 short lines in a casual colleague's voice. Start with the point or ask, put links inline, and use simple hyphens for dashes or bullets. For a small revision, change only the requested wording.
